Figure generation explanation

Main script
- The figures are generated by LLMS_analysis/Graphs/paper_summary_figures.R.

Purpose of the current script
- Build a publication-ready heatmap focused only on Cohen kappa.
- Compare model performance across papers and prompting configurations.
- Export the figure in both PDF and PNG formats.

Input data used
- Results files are read from LLMS_analysis/Results recursively.
- The script searches for files named like results_paper_*.csv.
- Each results file contains tag-level metrics for one model, one paper, one shot strategy, and one temperature.

Metadata extracted from file paths
- llm: taken from the first folder level under Results.
- paper_name: taken from the second folder level under Results.
- shot: extracted from the filename suffix type0shot or typefewshot.
- temperature: extracted from the filename segment _tempX.

Metric used in the figure
- Only cohen_kappa is used for the heatmap fill.
- If a file uses kappa instead of cohen_kappa, the script renames it internally to cohen_kappa for consistency.

Ground-truth data used for filtering
- The positive-case filter is not available in the results CSV files.
- To compute it, the script reads LLMS_analysis/Data/<paper_name>/real_answers.csv.
- For each tag, it counts how many true labels are equal to 1.
- Tags with fewer than 10 positive cases are excluded before aggregation.

How the heatmap values are built
- Start from tag-level cohen_kappa values in the results files.
- Join each tag with its positive-case count from the corresponding real_answers.csv file.
- Keep only evaluable tags with positive_n >= 10.
- Group by:
  - paper_name
  - llm
  - shot
  - temperature
- Compute:
  - mean_kappa: average cohen_kappa across remaining tags
  - evaluable_tag_n: number of retained tags in that cell

Heatmap structure
- Facets: one panel per paper.
- Rows: model (GPT, Gemini, Claude).
- Columns: configuration built as shot@temperature, for example fewshot@0.5.
- Fill: mean_kappa on a continuous 0 to 1 scale.
- Cell label: rounded kappa value plus N of evaluable tags.

Visual design choices
- Theme: theme_minimal with custom publication-style formatting.
- Facet titles use author-year labels:
  - Brandts and Cooper (2025)
  - Ederer and Schneider (2022)
  - Ling et al. (2025)
- Model labels are shown as GPT, Gemini, and Claude.
- The fill scale is designed to visually separate lower-agreement cells from stronger-agreement cells.
- Cells with kappa >= 0.80 receive a bold border as the visual indicator for strong agreement.

Output files
- LLMS_analysis/Graphs/paper_ready/figure1_cohen_kappa_heatmap_by_paper.pdf
- LLMS_analysis/Graphs/paper_ready/figure1_cohen_kappa_heatmap_by_paper.png

Important implementation note
- The script currently produces one combined faceted heatmap for all papers, not separate files per paper.
- If needed, this can be changed by splitting the plotting step into a loop over paper_name and saving one file per paper.
