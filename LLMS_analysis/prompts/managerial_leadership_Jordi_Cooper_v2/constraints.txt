LOGICAL CONSTRAINTS:

1. Suggestion hierarchy:
   - If 'any_suggestion': 0, then both 'suggest_safe': 0 and 'suggest_efficient': 0
   - If 'any_suggestion': 0.5, then 'suggest_safe' and 'suggest_efficient' can be at most 0.5
   - If 'any_suggestion': 1, then 'suggest_safe' and 'suggest_efficient' can be 0, 0.5, or 1 independently

2. Reporting logic:
   - 'receive_report' and 'neither_report' are mutually exclusive for clear cases:
     • If 'receive_report': 0, then 'neither_report': 1
     • If 'receive_report': 1, then 'neither_report': 0
   - Ambiguous case:
     • If 'receive_report': 0.5 (partial or unclear reporting), then 'neither_report': 0.5

3. Report content (only applies when 'receive_report': 1):
   - Exactly one of the following must equal 1, the others must be 0:
     • 'truthful'
     • 'falsehood'
     • 'contradict'
   - If 'receive_report': 0, then all three must be 0
   - If 'receive_report': 0.5, then at most one of (truthful, falsehood, contradict) may be 0.5, others must be 0
