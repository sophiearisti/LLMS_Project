README FILE for ICPSR 118729

This deposit contains data and script for reproducing the results published in “Trust and Promises over
Time.”

All direct identifiers (email addresses and names) have been removed.

Users should consult the investigator(s) if further information is needed.

Study Title: Trust and Promises over Time

Principal Investigator(s): Florian Ederer (Yale University) and Frederic Schneider (Cambridge University)

Summary of the collection:

The dataset includes data gathered in laboratory experiments at the University of Zurich and Yale
University.

datapaper_anonymized.dta : Data (Stata format)

datapaper_anonymized.xlsx : Data (Excel format)

datapaper_anonymized.csv : Data (comma-separated)

codebook.pdf : Codebook (PDF format)

codebook.xslx : Codebook (Excel format)

promises_over_time_replication_script.do : Stata script to replicate the results of the paper

Software requirements:

Stata (code was last run with version 16)

Restrictions:

No restrictions

Instructions:

All data are in one file “datapaper_anonymized.dta,” save the file to your disk and open the script
“promises_over_time_replication_script.do”. The script will run through and reproduce all the results
reported in the paper. Results are produced in order of appearance in the paper. Table and Figure

numbers are added for better orientation, and each output is accompanied by the fragment of text
where the result appears in the paper.
